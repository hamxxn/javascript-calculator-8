# JavaScript Calculator

입력한 문자열에서 숫자를 추출하여 더하는 계산기입니다.

## 기능 요구사항

### 1. 사용자 입력 처리

- 사용자에게 `"덧셈할 문자열을 입력해 주세요."` 메시지를 출력합니다.
- 입력된 문자열을 기반으로 덧셈 결과를 계산하여 `결과 : 6` 형식으로 출력합니다.

#### 세부 구현 사항

[] 사용자 입력을 받는 메서드  
→ `덧셈할 문자열을 입력해 주세요.` 메세지 출력합니다.
→ `MissionUtils.Console.readLineAsync()`를 사용해 사용자의 입력을 받습니다.
[] 계산 결과를 출력하는 메서드  
→ `"결과 : {result}"` 형식으로 출력합니다.

#### 출력 예시

```
입력: "1,2,3"
출력: 결과 : 6

입력: "1,2:3"
출력: 결과 : 6

입력: "//;\n1;2;3"
출력: 결과 : 6

입력: "//@\n1@2@3"
출력: 결과 : 6
```

---

### 2. 입력 검증

- 정규표현식을 사용하여 입력 형식을 검증합니다.
- 잘못된 입력 시 `[ERROR]`로 시작하는 메시지를 출력하고 프로그램을 종료합니다.

#### 세부 구현사항

[] 상수 정의
[] 에러 메시지 상수 (`ERROR_MESSAGES`)
[] 정규표현식 상수 (`REGEX_PATTERNS`)
[] 입력 검증 메서드
→ 정규표현식 상수를 사용해 커스텀 구분자(`//구분자\n숫자들`)와 기본 구분자(`,`, `:`) 형식을 검증합니다.
→ 잘못된 형식일 경우 error를 발생시키고, 에러 메시지 상수를 사용해 에러 메시지를 커스텀 합니다.
[] 커스텀 구분자 정규식 생성 로직 메서드
→ 커스텀 구분자에 따라 동적으로 숫자 형식을 검증하는 정규식을 생성합니다.

#### 허용되는 입력 형식

- **기본 구분자**: 쉼표(,) 또는 콜론(:)을 구분자로 사용하는 문자열(ex. "1,2,3", "1,2,3", "1,2:,3")
- **커스텀 구분자**: `//커스텀구분자\n문자열` 형식의 문자열(ex. "//;\n1;2;3")
- 숫자는 모두 양수만을 허용합니다.

---

### 3. 문자열 파싱

- 입력 문자열을 구분자 기준으로 분리하여 숫자 배열로 변환합니다.

[] 입력 문자열을 숫자 배열로 변환하는 메서드
→ 문자열을 구분자로 분리하여 숫자 배열로 반환합니다.

#### 예시

| 입력           | 구분자    | 결과 배열   |
| -------------- | --------- | ----------- |
| `"1,2:3"`      | `,` / `:` | `[1, 2, 3]` |
| `"//;\n1;2;3"` | `;`       | `[1, 2, 3]` |

---

### 4. 덧셈 연산

- 분리된 숫자들을 모두 더합니다.

#### 세부 구현 사항

[] `calculate(input)`
→ 빈 문자열이나 null 입력 시 0 반환합니다.
→ 숫자 배열을 모두 더해 연산 값을 반환합니다.
